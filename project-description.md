# Описание проекта

## Название

**«Живая книга проекта»** — интерактивная энциклопедия, которая растёт вместе с проектом.
Первый экземпляр — книга проекта «ИИ-ферма для BSF».

Короткое название репозитория: `living-project-book`.

## Проблема

Автор — инноватор, в работе несколько инновационных проектов одновременно. Проекты «живые»:
развиваются, меняют направление, состав и акценты, дополняются и сокращаются. При этом каждый
проект нужно показывать разным аудиториям — партнёрам, инвесторам, команде, кураторам — в разных
форматах, с разным таймингом и глубиной.

Материалы при этом распылены: исследования в PDF, расчёты в таблицах, презентации и переписка
отдельно. Каждая новая презентация или доклад собирается почти с нуля, знания не накапливаются,
а документы быстро устаревают вслед за проектом.

Нужен единый, постоянно обновляемый источник знаний по проекту — «энциклопедия проекта», из которой
можно быстро собрать презентацию, доклад или публикацию под конкретную аудиторию.

## Пользователь

- **Инноватор (автор)** — ведёт книгу: правит главы, добавляет новые, переиздаёт версии.
- **Партнёры и инвесторы** — читают книгу в браузере, без установки программ.
- **Команда и кураторы** — проверяют материалы и получают версии для работы.
- **ИИ-агент** — извлекает из книги материалы для презентаций, докладов и публикаций.
- **Другие инноваторы** — получают скилл и создают такие же книги для своих проектов.

## Основная функция

**Вход:** тексты глав, схемы, изображения, цифры и выводы из исследований проекта.

**Что делает сервис:**

- ведёт книгу как энциклопедию проекта: каждая глава — самостоятельный раздел;
- собирает книгу из отдельных глав и переиздаёт её после правок;
- показывает содержание, раскрывает главы, открывает окна со схемами, таблицами, расчётами и фото;
- собирает версии для внутреннего и внешнего пользования: папку, одиночный HTML-файл и ZIP;
- проверяет книгу автоматически в браузере;
- в перспективе — отдаёт ИИ-агенту структурированные материалы для презентаций и докладов.

**Выход:** готовая интерактивная книга в браузере, автономная версия одним файлом, архив для отправки.

**Инструменты:** HTML, CSS, JavaScript; Node.js для сборки, упаковки и проверки.

## Формат результата

- `index.html` — книга с обложкой, содержанием, 13 главами и модальными окнами;
- `index-standalone.html` — та же книга одним файлом, все изображения встроены;
- ZIP-архив с папкой книги и инструкцией для получателя;
- скилл `interactive-book-builder` — инструкция для ИИ-агента, позволяющая собрать такую же книгу
  для другого проекта.

## Минимальный функционал (MVP)

- 13 глав первой книги (проект BSF) с текстом и ссылками на окна;
- обложка и содержание;
- модальные окна со схемами, таблицами и фотографиями;
- правка каждой главы в отдельном файле;
- сборка книги одной командой;
- упаковка в папку, одиночный файл и ZIP;
- проверка ссылок и окон в браузере;
- универсальный скилл, по которому ИИ-агент создаёт книгу для нового проекта.

В дальнейшем: извлечение материалов для презентаций и докладов по запросу ИИ-агента, шаблоны
книг под разные типы проектов, публикация обновлений в интернете.

## Технологии

- **HTML5, CSS3, JavaScript (ES6)** — без фреймворков и внешних библиотек.
- **Node.js** — сборка книги, упаковка, автоматическая проверка; сторонних зависимостей нет.
- **JSON** — формат данных главы: заголовок, порядок, параграфы, тезисы, ссылки на окна.

## Состав репозитория

- `Landing-book/` — первая книга: страница, каркас, обложка, главы, изображения;
- `scripts/` — сборка, упаковка, проверка, скриншоты;
- `.claude/skills/interactive-book-builder/` — скилл для создания таких книг на других проектах;
- `screenshots/` — снимки работающей книги;
- `README.md` — инструкция и описание;
- `project-description.md` — этот документ.
