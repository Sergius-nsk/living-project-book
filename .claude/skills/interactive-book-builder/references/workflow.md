# Сценарии работы

## Содержание

- Новая книга с нуля
- Правка главы
- Добавление главы в конец
- Вставка главы между существующими
- Удаление главы
- Правка обложки и оформления
- Публикация пакета
- Миграция монолитной книги

## Новая книга с нуля

```bash
node scripts/scaffold-book.js --dir "C:\Projects\MyProject" --title "Название" --subtitle "Подзаголовок" --chapters 1
```

Скрипт создаст `book/`, `_shared/`, первую главу, скрипты сборки и упаковки.
Дальше:

1. Открыть `book/chapter-01/glava.html` в браузере — проверить, что каркас работает.
2. Заменить пример данных в `chapter-data` на реальный текст.
3. Заменить окно-пример `exampleModal` своим или удалить.
4. `node scripts/assemble-book.js --write --force` — собрать книгу.
5. Открыть `book/index.html`.

Для новой книги флаг `--force` нужен, потому что в шаблоне пустой массив глав
и предохранитель считает, что книга «потеряет» главы. После первой сборки флаг не нужен.

## Правка главы

1. `book/chapter-NN/glava.html` — открыть в браузере.
2. Править JSON `chapter-data` (текст) и блок между маркерами (окна).
3. Обновить `content.md`: статус, список параграфов, какие окна открывают ссылки.
4. `node scripts/assemble-book.js --write`.
5. `node scripts/package-book.js --name ...`, если книга уходит читателю.

Почему `content.md` важен: по нему человек и агент понимают структуру главы, не разбирая
JSON, и видят, что уже сделано. Расхождение между `content.md` и `glava.html` — сигнал,
что главу правили в спешке.

## Добавление главы в конец

1. Создать папку (например `chapter-06`) по образцу существующей главы.
2. В JSON задать `order` больше всех существующих (например 6, если последняя 5).
3. `node scripts/assemble-book.js --write`.

Имя папки может не совпадать с `order` — это нормально.

## Вставка главы между существующими

Между главой с `order: 3` и главой с `order: 4`:

1. Создать главу с `order: 3.5`.
2. Пересобрать.

В книге новая глава станет 4-й, прежняя 4-я — 5-й. Файлы остальных глав не меняются.

Повторная вставка между 3 и 3.5 — `order: 3.25`.

Сборщик падает, если два `order` совпадают, поэтому «немного меньше» или «немного больше»
недопустимы: нужно строго между.

## Удаление главы

1. Удалить папку главы.
2. `node scripts/assemble-book.js --write --force`.

Без `--force` сборщик откажется: он видит, что глав стало меньше, и считает это ошибкой.
Это защита от случайной потери текста при неверно указанной папке.

## Правка обложки и оформления

- Обложка: папка `cover/` — `cover.js` (разметка, клавиатура) и `cover.css` (стили и адаптив).
- Название книги: атрибуты `<body data-book-title data-book-subtitle>` в `index.html`
  и в каждом файле главы.
- Цвета: `:root` в начале `shell.css`.
- Новые стили блоков — в конец `shell.css`, чтобы не ломать существующие правила.

После правки каркаса пересобрать пакет: `node scripts/package-book.js`.

## Публикация пакета

```bash
node scripts/package-book.js --name "книга-для-партнёров"
```

Получается папка и ZIP в `dist/`. Внутри:

- `index.html` — книга с папками `_shared` и `assets`;
- `index-standalone.html` — всё в одном файле, для почты и мессенджеров;
- `README.txt` — инструкция получателю.

Проверить перед отправкой:

1. `node scripts/probe-browser.js --file dist/<имя>/index.html`.
2. Распаковать ZIP в чистую папку и открыть `index.html`.
3. Открыть `index-standalone.html` отдельно — без соседних папок.

## Миграция монолитной книги

Когда книга уже есть одним `index.html` с массивом глав:

1. **Каркас.** Вынести стили из `<style>` в `_shared/shell.css`, движок окон и содержания —
   в `_shared/shell.js`, обложку — в `cover/` (`cover.js` и `cover.css`). Если в книге своя вёрстка,
   оставить её в `shell.css` как есть: страница главы должна выглядеть так же, как книга.
2. **По одной главе.** Для каждой:
   - создать `chapter-NN/glava.html` по шаблону;
   - перенести данные главы из массива в `chapter-data`;
   - перенести окна этой главы в блок между маркерами;
   - открыть файл в браузере и сравнить с книгой.
3. **Ничего не пересобирать**, пока не перенесены все главы: книга продолжает работать
   в старом виде, а сборщик защищён предохранителем.
4. **После последней главы** добавить в `index.html` маркеры
   `<!-- CHAPTER-MODALS:START -->` / `<!-- CHAPTER-MODALS:END -->` вокруг области окон глав
   и `window.chaptersData = []` — затем `assemble-book.js --write --force`.
5. Пересобрать пакет.

Такой порядок безопасен: в любой момент можно остановиться, и книга останется целой.
