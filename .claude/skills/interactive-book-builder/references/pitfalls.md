# Грабли и как их обойти

Всё ниже проверено на реальной книге.

## Локальные файлы и браузер

`fetch()` из страницы, открытой по `file://`, блокируется браузером (CORS). Поэтому нельзя
«подгрузить» обложку или главу запросом. Работают только:

- `<link rel="stylesheet" href="../_shared/shell.css">` и `<link rel="stylesheet" href="../cover/cover.css">` — стили;
- `<script src="../cover/cover.js"></script>` — скрипт, который сам вставляет разметку обложки.

Если когда-нибудь понадобится настоящая подгрузка данных, потребуется локальный сервер.
Для книги он не нужен: обходимся подстановкой разметки скриптом.

## PowerShell и кириллица

Windows PowerShell 5.1 читает `.ps1` в системной кодировке. Файл с русскими строками,
сохранённый как UTF-8 без BOM, ломается с ошибками вида «Unexpected token».

Решение: сохранять `.ps1` в UTF-8 **с BOM**. Node.js и браузеры BOM не мешает.

Для `.js` и `.html` BOM не обязателен, но и не вредит.

## Полоса прокрутки в модальном окне

Если прокрутка висит на `.modal-content` (`max-height: 80vh; overflow-y: auto`), полоса
оказывается внутри скруглённой рамки и визуально наезжает на правую границу.

Правильно: прокручивается подложка.

```css
.modal-overlay { align-items: flex-start; overflow-y: auto; padding: 40px 0; }
.modal-content { margin: auto; /* без max-height и overflow */ }
```

## Встраивание изображений в одиночный файл

`index-standalone.html` собирается заменой путей `assets/...` на `data:image/...;base64,...`.
Правила:

- заменять все вхождения пути, а не только первое;
- тип брать по расширению (`.webp` → `image/webp`, `.svg` → `image/svg+xml`);
- встраивать после подстановки CSS, иначе картинки из CSS останутся внешними;
- не встраивать дважды: сначала собрать уникальный список путей.

## ZIP и Проводник Windows

Если открыть `index.html` двойным щелчком прямо из окна архива, Проводник распакует
только сам файл, без папок `_shared` и `assets`. Книга откроется без оформления.
Поэтому в `README.txt` пишем: сначала «Извлечь все…», и отдельно предлагаем
`index-standalone.html`, который работает без соседних файлов.

## Уникальность id окон

Все окна попадают в один документ книги. Два окна с `id="infoModal"` в разных главах
приведут к тому, что откроется первое. Сборщик проверяет id и падает при повторе —
не отключайте эту проверку.

## Ссылки по слову

Ссылка ставится по вхождению `label` в текст тезиса. Если слово изменили в тексте,
а `label` забыли — ссылка молча исчезнет. Поэтому после правки главы:

1. открыть её в браузере;
2. пройтись по ссылкам;
3. при автоматической проверке — `node scripts/probe-browser.js` покажет `modal: null`.

## Пути к изображениям

В файле главы (`book/chapter-01/...`) путь начинается с `../assets/...`.
В книге (`book/index.html`) — с `assets/...`. Сборщик приводит первые ко вторым.
Если картинка появилась в окне главы, но пропала в книге — почти всегда это забытый `../`.

## Кэш браузера

После правки `_shared/shell.css` или `shell.js` браузер может показать старую версию.
Обновлять с `Ctrl+F5`. Для проверки упакованной книги — открывать из новой папки.

## Предохранитель сборки

`assemble-book.js` отказывается писать, если глав в файлах меньше, чем сейчас в книге.
Это не баг, а защита: так случайно удалённая папка не уничтожит главу в книге.
Если уменьшение намеренное — `--force`.

## Один источник правды

`index.html` — результат сборки. Если править главы прямо в нём, следующая сборка
затрёт правки без предупреждения. В шаблоне это написано комментарием; не удаляйте его.
