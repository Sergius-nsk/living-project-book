# Архитектура книги

## Содержание

- Макет папок
- Файл главы: три обязательных блока
- Схема JSON главы
- Контракт движка
- Оформление: какие классы доступны
- Правила нумерации

## Макет папок

```
project/
  book/
    index.html                 — книга; генерируется сборщиком
    _shared/
      shell.css                — стили каркаса: содержание, окна, блоки содержимого
      shell.js                 — содержание, раскрытие, окна, Esc
    cover/
      cover.css                — стили обложки и адаптив
      cover.js                 — обложка; подставляется в #cover-host
    chapter-01/
      glava.html               — данные главы + её окна
      content.md               — описание главы для человека
    chapter-02/
      ...
    assets/
      img/...                  — изображения, пути от корня книги
  scripts/
    scaffold-book.js
    assemble-book.js
    package-book.js
    probe-browser.js
  dist/                        — пакеты для отправки
```

Папки глав можно называть как угодно: сборщик ищет файлы по маркерам, а не по именам.
`chapter-NN` — просто удобная привычка.

## Файл главы: три обязательных блока

1. **Подключение каркаса** в `<head>`:
   `<link rel="stylesheet" href="../_shared/shell.css">`
   `<link rel="stylesheet" href="../cover/cover.css">`
2. **Окна главы** между маркерами:
   ```html
   <!-- CHAPTER-MODALS:START -->
   ...разметка окон...
   <!-- CHAPTER-MODALS:END -->
   ```
3. **Данные главы** перед скриптами:
   ```html
   <!-- CHAPTER-DATA:START -->
   <script type="application/json" id="chapter-data">{ ... }</script>
   <!-- CHAPTER-DATA:END -->
   ```

В конце `<body>`:

```html
<script src="../cover/cover.js"></script>
<script src="../_shared/shell.js"></script>
```

Маркеры и JSON обязательны: сборщик находит главу именно по ним. Если маркеров нет,
файл считается обычной страницей и игнорируется — это позволяет держать в папке книги
черновики и старые версии, не рискуя их опубликовать.

## Схема JSON главы

```json
{
  "order": 3,
  "title": "Название главы одной фразой",
  "ready": true,
  "content": [
    {
      "title": "Название параграфа",
      "theses": [
        "Тезис строкой.",
        {
          "text": "Тезис со ссылкой на окно: слово ссылка.",
          "links": [{ "label": "ссылка", "modal": "exampleModal" }]
        }
      ]
    }
  ]
}
```

- `order` — число, порядок в книге. Целые 1, 2, 3…; дробные для вставок (3.5).
- `title` — строка заголовка в оглавлении.
- `ready` — `true` раскрывает содержание; `false` оставляет главу свёрнутой.
- `content[].title` — заголовок параграфа; в книге сейчас не выводится отдельной строкой,
  но остаётся в данных и в `content.md`.
- Тезис — либо строка, либо объект `{ text, links }`.
- `links[].label` обязан встречаться в `text`. Ссылка ставится по первому вхождению.
  Это сделано ради простоты: редактору не нужно размечать HTML внутри строки.

## Контракт движка

`_shared/shell.js` работает в двух режимах и сам определяет, какой включить:

| Условие на странице | Режим | Нумерация |
|---|---|---|
| есть `<script id="chapter-data">` | страница главы | из `order`, если целое; иначе без номера |
| объявлен `window.chaptersData` | книга | сквозная по позиции: 1, 2, 3… |

Обеспечивает: раскрытие содержания, открытие/закрытие окон, Esc (окно → глава → содержание),
возврат фокуса, `aria-`атрибуты.

`cover/cover.js` вставляет обложку в `<div id="cover-host"></div>`; её вид задаёт
`cover/cover.css`. Название и подзаголовок читаются из
`<body data-book-title="..." data-book-subtitle="...">`.
Поэтому обложка одна на книгу и на все главы и правится в одной папке — независимо
от каркаса.

## Оформление: какие классы доступны

В `shell.css` уже есть:

- карточки: `.project-grid`, `.project-card`;
- таблицы сравнения: `.compare-wrap`, `.compare-table`, `.hierarchy-table`;
- цепочка шагов: `.chain`, `.chain-step`, `.chain-arrow`;
- диаграмма: `.bsf-diagram` (или любой `svg` внутри блока);
- галерея фото: `.waste-gallery`, `.waste-item`, `.waste-caption`;
- полосы затрат: `.cost-compare`, `.cost-row`, `.cost-label`, `.cost-track`, `.cost-fill.red/gray/green`;
- окна: `.modal-overlay`, `.modal-content`, `.modal-close`.

Цвета меняются в `:root` в начале `shell.css`: `--bg-color`, `--surface-color`,
`--accent-color`, `--text-main`, `--text-dim`. Этого достаточно, чтобы перекрасить книгу
под другой проект.

## Правила нумерации

- В книге номер = позиция после сортировки по `order`. Дробные значения не видны.
- Вставка главы не требует перенумерации остальных файлов.
- Одинаковый `order` у двух глав — ошибка сборки.
- Имена папок на нумерацию не влияют.
