Проблема

Проекты живые.
Документы — нет.

01

Материалы распылены

Исследования в PDF, расчёты в таблицах, презентации и переписка — отдельно.

02

Проекты меняются

Направление, состав и акценты обновляются быстрее, чем документы.

03

Каждая презентация — с нуля

Новая аудитория, формат и тайминг — значит, новая сборка материалов.

Нужен единый источник знаний, который обновляется вместе с проектом.
Решение

Энциклопедия проекта,
а не отдельный документ

Одна книга. Тринадцать глав. Обновляется вместе с проектом.
Главы независимы: правлю одну — остальные не трогаю.
Переиздание одной командой: книга собирается заново из глав.
Из книги ИИ-агент соберёт презентацию, доклад и короткое резюме под конкретную аудиторию.
Первый экземпляр — проект переработки пищевых отходов с помощью чёрной львинки.
Как устроено

Книга собирается, а не пишется

book/

_shared/общий каркас
cover/обложка
chapter-01…13/главы
assets/изображения
scripts/

packageпакет для отправки
probeпроверка в браузере
.claude/skills/
builderскилл: собрать такую же книгу для другого проекта
Одна глава — один файл. Новая глава вставляется между существующими без перенумерации: порядок задаёт поле order.
HTML, CSS, JavaScript, Node.js — без внешних зависимостей.
