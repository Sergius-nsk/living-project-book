# Глава 5: Проблемы внутри современного техпроцесса ферм BSF.

## Статус: Готово (вынесена из книги, 30.10.2026)

Рабочий файл — `glava-5.html`. Стили и движок — в `../_shared/`.
Текст правится в JSON-блоке `chapter-data`, окна — между маркерами `CHAPTER-MODALS`.

**Ссылка в заголовке:** «современного техпроцесса» → techMapModal

## Параграф 1

- Первая проблема очевидна – много ручного труда. Решение – сокращение ФОТ путём автоматизации всего производства. Это сразу делает цену БЛК конкурентной с рыбной мукой.
  - ссылка «конкурентной» → blkCostModal

## Параграф 2

- Как ни странно, самой по себе автоматизации не достаточно для снижения себестоимости БЛК.
  - ссылка «не достаточно» → automationCostModal

## Параграф 3

- Масштабирование BSF-ферм в большую сторону не приводит к улучшению показателей бизнеса.
  - ссылка «в большую сторону» → scaleModal

## Параграф 4

- Новые вертикальные архитектурные решения для сокращения стоимости земельного участка тоже не дают желаемого результата.
  - ссылка «вертикальные» → verticalModal
