# Глава 1: Рециклинг и экология

## Статус: Готово (вынесена из книги, 30.10.2026)

Рабочий файл — `glava-1.html` (15 176 байт). Открывается в браузере как самостоятельная
страница: обложка → содержание → глава. Стили и движок берутся из `../_shared/`:
`shell.css`, `shell.js`, `cover.js`. Обложка общая для всех глав и для книги —
правится только в `_shared/cover.js`.

## Как править

- Текст главы — в JSON-блоке `chapter-data` внутри `glava-1.html`.
- `order` — порядок в книге. Целые числа 1, 2, 3…; для вставки между главами
  достаточно дробного значения (3.5 встанет между 3 и 4), перенумеровывать остальные не нужно.
  В книге нумерация всегда сквозная: 1, 2, 3, …
- Модальные окна — между маркерами `<!-- CHAPTER-MODALS:START -->` и `<!-- CHAPTER-MODALS:END -->`.
- Ссылка на окно задаётся в тезисе:
  `{ "text": "...", "links": [{ "label": "Отходы", "modal": "wasteModal" }] }`.
  `label` должно встречаться в тексте — по этому слову ставится ссылка.
- Изображения — `../assets/img/...`; при сборке книги префикс `../` убирается.

## Параграф 1: Определение отходов

**Тезис:** Отходы — это бывшие в употреблении и пришедшие в негодность вещи, либо продукты, сопутствующие нужным вещам.

**Интерактив:** ссылка «Отходы» → окно `wasteModal` — реальность отходов: цифры UNEP, два фото, источник.

## Параграф 2: Концепция возврата к жизни

**Тезис:** Если отходы — это бывшие нужные вещи, то можно попробовать «вернуть их к жизни» — снова сделать из них нужные вещи.

## Параграф 3: Циркулярная экономика

**Тезис:** Из этого тезиса возникла и развивается циркулярная экономика (рециклинг).

**Интерактив:** ссылка «рециклинг» → окно `recycleModal` — циркулярная экономика: иерархия обращения с отходами, таблица шагов, схема БСФ, мировые лидеры (Entobel, Innovafeed, Protix).
